# Privacy Policy - DevPulse Engine

**Last Updated: August 1, 2026**

## 1. Overview
DevPulse ("Application") respects user privacy and enforces data minimization principles.

## 2. Information Collected
- **Search Queries**: Query terms sent to the search engine are processed ephemerally and cached locally for performance optimization.
- **Client IP & Logs**: Server logs store client IP addresses temporarily for rate limiting and security audit trails.

## 3. Data Protection & Security
- All traffic between client and server is encrypted via TLS/HTTPS.
- HMAC signatures verify request authenticity.
- No personal user data is sold, traded, or shared with third parties.

## 4. Contact
For privacy inquiries, contact `security@devpulse.app`.
